# 📋 제품 사양서 (Product Specification)

## 1. 인증 화면 (Authentication)

### 1.1 로그인 (Login)
**화면**: 01 로그인

| 요소 | 명세 |
|-----|------|
| 제목 | "팀 업무 스케줄러" + "로그인하여 시작하세요" |
| 입력 필드 | 이메일 (required), 비밀번호 (required) |
| 버튼 | 로그인 (Primary), 회원가입 (Secondary) |
| 링크 | ID 찾기 \| 비밀번호 찾기 |
| 에러 | 빨강 배경, "이메일 또는 비밀번호가 올바르지 않습니다" |
| 성공 | 메인 화면(개인뷰)으로 리다이렉트 |

**비즈니스 규칙**
- 이메일 형식 검증 필수
- 비밀번호 최소 8자 이상
- 실패 시 구체적인 오류 메시지는 노출하지 않기 (보안)

### 1.2 회원가입 (Sign Up)
**화면**: 02 회원가입

| 요소 | 명세 |
|-----|------|
| 입력 필드 | 이름 (required), 이메일 (required), 비밀번호 (required), 비밀번호 확인 (required), 직급 (required) |
| 직급 옵션 | 일반 \| 상위 직급 |
| 안내문 | "상위 직급은 관리자 승인 필요" |
| 버튼 | 가입 신청 (Primary) |
| 링크 | "이미 계정이 있으신가요? 로그인" |

**비즈니스 규칙**
- 이메일 중복 체크
- 비밀번호 규칙: 8자 이상, 영문+숫자 포함
- 상위 직급 선택 시 → Admin 권한 신청 상태 (SA 승인 대기)
- 일반 선택 시 → Member 권한으로 즉시 가입

### 1.3 ID/PW 찾기 (Find Credentials)
**화면**: 03 ID/PW 찾기

#### ID(이메일) 찾기
| 요소 | 명세 |
|-----|------|
| 입력 필드 | 이름 (required) |
| 버튼 | 이메일 찾기 |
| 결과 | "가입된 이메일: kim***@company.com" (마스킹) |

#### 비밀번호 찾기
| 요소 | 명세 |
|-----|------|
| 입력 필드 | 이메일 (required) |
| 버튼 | 임시 비밀번호 발송 |
| 결과 | "임시 비밀번호를 이메일로 발송했습니다" |

**비즈니스 규칙**
- 임시 비밀번호는 이메일로만 발송 (SMS 불가)
- 임시 비밀번호 유효 기간: 24시간

## 2. 메인 화면 (Dashboard)

### 2.1 레이아웃
**화면**: 04 메인화면 (개인뷰 · Daily View)

| 영역 | 설명 |
|-----|------|
| 공지 배너 | 상단 고정, 보라색 배경, "📢 공지" 아이콘 + 메시지 + 추가 버튼 + 닫기 |
| 상단바 | "팀 업무 스케줄러" + 탭(개인뷰/팀뷰/달력뷰) + 사용자 아바타 |
| 좌측 패널 | "대기 목록" + Card 형식 Task 표시 + "+ Task 추가" |
| 우측 영역 | 시간표(오늘) + 시간별 Task 표시 |

### 2.2 공지 배너 (Notice Bar)
```
📢 공지 | 내일 오후 2시 서버 점검 예정입니다... | [+ 공지 등록] [×]
```

| 속성 | 값 |
|-----|-----|
| 배경색 | 보라색 (#7C3AED) |
| 텍스트색 | 밝은 보라 (#F5F3FF) |
| 고정 위치 | 페이지 최상단 |
| 닫기 기능 | 클릭 시 숨김 (세션 내 유지) |
| 공지 등록 | 클릭 시 "공지 등록 모달" 열기 |

**비즈니스 규칙**
- 로그인된 모든 사용자에게 표시
- 닫으면 세션 동안 표시 안 함
- 새로운 공지 → 자동 재표시
- 브라우저 리로드 시 다시 표시

### 2.3 탭 네비게이션
```
[개인뷰] [팀뷰] [달력뷰]
```

| 탭 | 권한 | 표시 |
|----|------|------|
| 개인뷰 | 전체 | 활성화 (파란색) |
| 팀뷰 | Member만 안 보임 | 조건부 표시 |
| 달력뷰 | 전체 | 활성화 (파란색) |

### 2.4 대기 목록 (Waiting List)
```
대기 목록    [+]
┌─────────────┐
│ 보고서 초안  │
│ 담당: 김OO  │
└─────────────┘
│ 코드 리뷰    │
│ 담당: 김OO  │
└─────────────┘
┌─────────────┐
│ + Task 추가 │
└─────────────┘
```

| 속성 | 값 |
|-----|-----|
| 너비 | 150px (고정) |
| Task 카드 | 제목(굵게) + 담당자(작은글씨) |
| 추가 버튼 | "+ Task 추가" (점선 배경) |
| 스크롤 | 넘치는 Task는 스크롤 가능 |

**비즈니스 규칙**
- 대기 목록 = 아직 시간 미지정 Task
- 최대 10개까지 표시, 이상은 스크롤
- 드래그로 시간표에 추가 가능 (향후 기능)

### 2.5 시간표 (Time Table)
```
2026년 4월 26일 (일)  ◀ ▶

시간  | 일정
-----|──────────────────────────────
07:00 | [기획서 작성 완료] ✓ 완료
08:00 | [주간 보고서]    [API 명세 검토]
      | 진행중 (1/2)     진행중 (2/2)
09:00 | (위 이어짐)      (위 이어짐)
10:00 | [코드리뷰] [DB설계] [문서화]
      | 지연(1/3) 진행중(2/3) 대기(3/3)
```

| 속성 | 값 |
|-----|-----|
| 시간 범위 | 07:00 ~ 20:00 (조정 가능) |
| 행 높이 | 42px/hour |
| 동시 Task | 가로 균등 분할 (너비 = 100% / 개수) |
| 색상 | 상태별 색상 (파랑, 초록, 빨강, 회색) |
| 표시 형식 | "Task명 [상태 Badge]" |
| 다중 Task 라벨 | "← n개 · 각 1/n" (우상단) |

**비즈니스 규칙**
1. **같은 시간대 중첩 Task**
   - 2개 → 각 50%
   - 3개 → 각 33%
   - 4개 → 각 25%
   - 5개 이상 → 각 20% (권장 최대)

2. **날짜 이동**
   - ◀ 버튼 → 전날
   - ▶ 버튼 → 다음날
   - 이전/다음 월로 이동 가능

3. **지연 Task 호버**
   - 마우스 호버 시 지연 사유 표시
   - 툴팁 배경: 밝은 빨강 (#FEF2F2)
   - 지연 사유 텍스트 표시
   - 예: "v2 API 스펙 변경으로 인해 전면 재작성 필요"

### 2.6 Task 상태 색상
| 상태 | 색상 | 배경 | 텍스트 |
|-----|-----|-----|-------|
| 대기 (PENDING) | 회색 | #F9FAFB | #6B7280 |
| 진행중 (IN_PROGRESS) | 파랑 | #EFF6FF | #1D4ED8 |
| 완료 (COMPLETED) | 초록 | #F0FDF4 | #15803D |
| 지연 (DELAYED) | 빨강 | #FEF2F2 | #DC2626 |

## 3. 달력 화면 (Calendar)

### 3.1 개인 달력뷰 (Personal Calendar)
**화면**: 05 개인 달력뷰

| 속성 | 값 |
|-----|-----|
| 월간 표시 | Grid 7열 (일~토) |
| 각 칸 | 날짜 + Task 목록 |
| Task 표시 | "[상태색] Task명 ..." |
| 초과 시 | "..." 생략 |
| 배경색 | 오늘 날짜는 밝은 파랑 (#EFF6FF) |

**기능**
- 월 이동: ◀ / ▶
- 기간 Task: 시작~종료일 모든 날짜에 반복 표시
- 클릭: 해당 날짜의 Daily View로 이동
- 상태별 색상 유지

### 3.2 팀 달력뷰 (Team Calendar)
**화면**: 06 팀 달력뷰

개인 달력뷰와 동일하지만:
- **팀원 필터 탭**: "전체 / 김OO / 이OO / 박OO / ..."
- **Task 표시**: "[상태색] Task명 (담당자명: ...)" 형식
- **필터 기능**: 탭 클릭 시 해당 팀원의 Task만 표시
- **Access Control**: Member는 보이지 않음 (Admin+ 필수)

## 4. Task 모달 (Modals)

### 4.1 Task 등록 모달 (Create Task)
**화면**: 07 Task 등록 모달

```
┌─────────────────────────┐
│ Task 등록               │
├─────────────────────────┤
│ 제목 * [          ]     │
│                         │
│ 담당자 * 여러 명 추가 가능│
│ [김OO ×]                │
│ [+ 담당자 추가  ▾]      │
│                         │
│ 시작 일시 * │ 종료 일시 *│
│ [2026-04-26] [2026-04-28]│
│ [09:00]      [18:00]    │
│                         │
│ ⓘ 종료일이 다르면 기간   │
│   Task로 처리됩니다      │
│                         │
│ 메모                    │
│ [             ]         │
│ (선택)                  │
│                         │
│ [취소] [저장]           │
└─────────────────────────┘
```

| 필드 | 타입 | 검증 |
|-----|------|------|
| 제목 | 문자열 | required, 최대 100자 |
| 담당자 | 배열 | required, 1명 이상 |
| 시작 일시 | DateTime | required |
| 종료 일시 | DateTime | required, 시작 이후 |
| 메모 | 문자열 | optional, 최대 500자 |

**비즈니스 규칙**
- 담당자는 다중 선택 가능
- 기간 Task: 자동으로 매일 달력에 반복
- 중복 담당자는 허용 안 함

### 4.2 Task 수정 모달 (Edit Task - Admin/SA Only)
**화면**: 08 Task 수정 모달

등록 모달과 유사하지만:

```
┌──────────────────────────────────────┐
│ Task 수정  [지연] [상위 직급]        │
├──────────────────────────────────────┤
│ 제목 * [API 명세 검토]               │
│                                      │
│ 담당자 * 추가/제외 가능              │
│ [이OO ×] [박OO ×]                   │
│ [+ 담당자 추가  ▾]                  │
│                                      │
│ 시작 │ 종료                          │
│ [2026-04-26 11:00] [2026-04-28 18:00]│
│                                      │
│ 메모                                 │
│ [v2 API 명세 포함 필요]              │
│                                      │
│ ⚠ 지연 사유                         │
│ └─ v2 API 스펙 변경으로...          │
│    기록일시: 2026-04-26 12:05       │
│                                      │
│ 최종 수정자                          │
│ 김OO (상위 직급) · 방금 전          │
│                                      │
│ [취소] [삭제] [저장]                │
└──────────────────────────────────────┘
```

**추가 요소**
- 상태 배지: "지연" (빨강)
- 권한 배지: "상위 직급" (주황)
- 지연 사유 표시 (박스)
- 최종 수정자 및 시간 표시
- 삭제 버튼 추가

**권한**
- Admin 이상만 수정 가능
- 삭제도 Admin 이상만 가능

### 4.3 Task 상세 모달 (View Task - Read Only)
**화면**: 09 Task 상세 (읽기 전용)

수정 모달과 동일하지만:
- 모든 입력 필드가 **읽기 전용** (비활성화)
- 삭제 버튼 없음
- "수정은 상위 직급만 가능합니다" 메시지
- 닫기 버튼만 활성화

## 5. 팝업 & 얼럿 (Alerts & Popups)

### 5.1 Task 삭제 얼럿
**화면**: 10 삭제 확인 얼럿

```
┌──────────────────────────┐
│ ! Task를 삭제하시겠습니까? │
├──────────────────────────┤
│ 삭제할 Task:             │
│ [API 명세 검토]          │
│                          │
│ ⚠ 삭제 후 복구할 수     │
│   없습니다.              │
│                          │
│ [취소] [삭제]            │
└──────────────────────────┘
```

| 요소 | 설명 |
|-----|------|
| 아이콘 | 느낌표 (빨강, 원형) |
| Task 명 | 정보 박스에 표시 |
| 경고 | "삭제 후 복구할 수 없습니다" (빨강) |
| 버튼 | 취소 (2차), 삭제 (1차, 빨강) |

**비즈니스 규칙**
- 삭제 확인 없이는 삭제 불가
- 삭제 후 즉시 목록에서 제거

**화면**: 11 Task 지연 알림

```
┌──────────────────────────┐
```

**비즈니스 규칙**
- Task 종료 시간 초과 시 자동 팝업
- 사유 필수 입력
- 연장 선택 시 자동 갱신
- 연장은 최대 3회까지만 가능

## 6. 관리자 페이지 (Admin Panel)

### 6.1 Super Admin 페이지 구성
**화면**: 13 Super Admin 페이지

#### 팀원 목록 (좌측 2/3)
```
팀원 목록                    [+ 팀원 추가]
┌──────────────────────────────────────┐
│ 이름/이메일  │ 권한      │ 상태 │ 관리│
├──────────────────────────────────────┤
│ 김OO        │ 슈퍼관리자 │ 활성 │ 편집│
│ kim@company │             │     │    │
├──────────────────────────────────────┤
│ 이OO        │ 관리자     │ 활성 │ 편집│
│ lee@company │             │     │    │
├──────────────────────────────────────┤
│ 박OO        │ 일반       │ 활성 │ 편집│
│ park@...    │             │     │    │
├──────────────────────────────────────┤
│ 정OO        │ 일반       │ 비활성│ 편집│
│ jung@...    │             │     │    │
└──────────────────────────────────────┘
```

| 컬럼 | 값 |
|-----|-----|
| 이름/이메일 | 정보 표시 |
| 권한 | 슈퍼관리자 / 관리자 / 일반 (배지) |
| 상태 | 활성 (초록) / 비활성 (빨강) |
| 관리 | "편집" 링크 |

**비즈니스 규칙**
- 권한 변경: SA > Admin > Member 순 (강등만 가능)
- 상태 변경: 활성 ↔ 비활성
- 비활성화: 로그인 차단, 계정 삭제 아님
- 편집 클릭 → 팀원 수정 모달 (향후)

## 7. 전역 UI 요소

### 7.1 아바타
```
M (초록)  - Member
A (주황)  - Admin
S (보라)  - Super Admin
```

| 크기 | 사용처 |
|-----|--------|
| 24px | 상단바 |
| 20px | 리스트 |
| 16px | 인라인 |

### 7.2 배지 (Badge)
```
[슈퍼관리자] [관리자] [일반]  - 권한
[활성]       [비활성]        - 상태
[진행중]     [완료]          - Task 상태
[지연]                       - Task 상태
[상위 직급]  [읽기 전용]    - Task 권한
[전체 공개]                  - 공지
```

### 7.3 버튼 타입
```
[Primary] - 파란색, 전체 너비의 2/3, 주요 액션
[Secondary] - 회색 테두리, 전체 너비의 1/3, 보조 액션
[Danger] - 빨강 테두리, 빨강 텍스트, 삭제/위험
[Delete] - 빨강 배경, 흰색 텍스트, 삭제 확정
```

### 7.4 폼 필드
```
[입력 필드]      - 흰색 배경, 회색 테두리
[입력 필드(채움)] - 흰색 배경, 회색 텍스트
[읽기 전용]      - 회색 배경, 비활성
```
