**목표**: 사용자의 일일 스케줄을 시간표 형식으로 보여주고, 대기 중인 Task를 관리하는 메인 화면 구현

**상태**: ⏳ 개발 대기 중

## 세부 컴포넌트

### 1. 대기 목록 (Waiting List)

**역할**: 시간이 아직 정해지지 않은 Task를 표시

**레이아웃**
```
대기 목록    [+]
┌─────────────────┐
│ 보고서 초안     │
│ 담당: 김OO      │
├─────────────────┤
│ 코드 리뷰       │
│ 담당: 박OO      │
├─────────────────┤
│ [+ Task 추가]   │
└─────────────────┘
```

**속성**

| 속성 | 값 |
|-----|-----|
| 너비 | 150px (고정) |
| 최대 Task 개수 | 10개 |
| 초과 시 | 스크롤 가능 |

**Task 카드 구성**
- 제목 (굵게, 최대 20자)
- 담당자 (작은 글씨, 마스킹: "담당: 김OO")
- 배경색: 흰색
- 테두리: 1px #E5E7EB

**[+ Task 추가] 버튼**
- 스타일: 점선 테두리, 회색 텍스트
- 클릭 시: Task 등록 모달 열기 (Phase 4.1)

---

### 2. 시간표 (Time Table)

**역할**: 오늘의 시간별 Task 일정을 시각화

**레이아웃**
```
2026년 4월 26일 (일)  ◀ ▶

시간 | 일정
-----|─────────────────────────────
07:00 | [기획서 작성 완료] ✓
08:00 | [주간 보고서]    [API 명세 검토]
      | 진행중 (1/2)     진행중 (2/2)
09:00 | (위 이어짐)      (위 이어짐)
10:00 | [코드리뷰] [DB설계] [문서화]
      | 지연(1/3) 진행중(2/3) 대기(3/3)
```

**시간 범위**
- 시작: 07:00
- 종료: 20:00 (조정 가능)
- 총 13개 시간대

**Task 표시**

| 상태 | 배경색 | 텍스트색 | Badge |
|-----|-------|--------|--------|
| 대기 (PENDING) | #F9FAFB | #6B7280 | 회색 |
| 진행중 (IN_PROGRESS) | #EFF6FF | #1D4ED8 | 파랑 |
| 완료 (COMPLETED) | #F0FDF4 | #15803D | 초록 |
| 지연 (DELAYED) | #FEF2F2 | #DC2626 | 빨강 |

**동시 Task 처리**
- 같은 시간대에 여러 Task가 있으면 가로 균등 분할
- 2개: 각 50%
- 3개: 각 33%
- 4개: 각 25%
- 5개 이상: 각 20%

**다중 Task 라벨**
```
예시: "← 3개 · 각 1/3"
```
- 위치: Task 카드 우상단
- 색상: 어두운 회색

**날짜 이동**
- ◀ 버튼: 전날
- ▶ 버튼: 다음날
- 월 경계: 자동으로 다음/이전 월로 이동

**호버 효과**
- Task 카드 호버 시 그림자 추가
- 지연 Task 호버 시 지연 사유 툴팁 표시
  ```
  배경: #FEF2F2 (밝은 빨강)
  텍스트: #DC2626 (빨강)
  예: "v2 API 스펙 변경으로 인해 전면 재작성 필요"
  ```

## Task 데이터 구조

```javascript
{
  id: "task-001",
  title: "보고서 초안 작성",
  description: "프로젝트 X 분기 보고서",
  status: "IN_PROGRESS",  // PENDING, IN_PROGRESS, COMPLETED, DELAYED
  assignees: ["kim123", "lee456"],  // 담당자 배열
  startDate: "2026-04-26",
  startTime: "09:00",
  endDate: "2026-04-26",
  endTime: "11:00",
  priority: "HIGH",  // LOW, MEDIUM, HIGH
  delayReason: "상위 Task 지연으로 인해 연쇄 지연",
  memo: "추가 메모",
  createdAt: "2026-04-25T10:30:00Z",
  updatedAt: "2026-04-26T09:00:00Z"
}
```
