# 📊 프로젝트 개요

## 프로젝트명
**팀 업무 스케줄 관리 시스템** (Team Task Scheduler)

---

## 프로젝트 목표

팀의 업무 일정을 한눈에 관리하고 협업 효율성을 극대화하는 웹 기반 통합 스케줄 관리 시스템 구축

### 주요 목표
1. 개인/팀 일정을 체계적으로 관리
2. 지연 업무에 대한 실시간 알림
3. 권한에 따른 세분화된 접근 제어
4. 직관적인 UI로 진입 장벽 최소화
5. 모바일 환경에서도 쾌적한 사용성

---

## 주요 기능

### 1️⃣ 인증 시스템 (Authentication)
| 기능 | 설명 |
|-----|------|
| 로그인 | 이메일 + 비밀번호 기반 |
| 회원가입 | 이름, 이메일, 비밀번호, 직급(권한 신청) |
| ID 찾기 | 이름으로 가입 이메일 검색 |
| PW 찾기 | 이메일로 임시 비밀번호 발송 |

### 2️⃣ 메인 화면 (Personal Daily View)
- **공지 배너**: 상단 고정 공지사항 표시
- **대기 목록**: 아직 일정 등록되지 않은 Task
- **시간표**: 오늘의 시간별 Task 표시
- **동시 표시**: 같은 시간대 Task 자동 균등 분할
- **지연 표시**: 지연된 Task 특별 표시 + 호버 시 지연 사유 표시

### 3️⃣ 달력 화면
#### 개인 달력뷰 (Personal Calendar)
- 본인의 모든 Task 월간 표시
- 기간 Task는 해당 기간 내 모든 날짜에 반복 표시
- 칸 초과 시 "..." 표시로 공간 효율화
- 날짜 클릭 → Daily View로 이동

#### 팀 달력뷰 (Team Calendar)
- 팀 전체의 Task를 한눈에 확인
- 팀원 필터 탭으로 선택적 조회
- 담당자 이름을 Task와 함께 표시
- 그룹 기반 필터 지원

### 4️⃣ Task 관리
#### Task 상태
- **대기 (PENDING)**: 회색 - 아직 시작하지 않음
- **진행중 (IN_PROGRESS)**: 파랑 - 진행 중
- **완료 (COMPLETED)**: 초록 - 완료됨
- **지연 (DELAYED)**: 빨강 - 종료 일시 초과

#### Task 생성 (등록 모달)
- 제목, 담당자(복수 선택), 시작/종료 일시, 메모
- 담당자는 여러 명 추가 가능
- 종료일이 시작일과 다르면 → 기간 Task로 처리

#### Task 수정 (수정 모달)
- Admin 이상만 가능
- 지연 Task는 지연 사유 표시
- 지연 사유 기록 (기록 일시 포함)
- 최종 수정자 정보 표시
- 삭제 기능 포함

#### Task 상세 조회 (읽기 전용)
- Member 권한은 수정 불가 상태로 표시
- 모든 정보 조회 가능
- 닫기 버튼만 활성화

### 5️⃣ Task 지연 처리
- Task 종료 일시 초과 시 지연 팝업 표시
- **필수 입력**: 지연 사유
- **선택 사항**: 1시간/하루 연장
- 연장 선택 시 종료 일시 자동 갱신

### 6️⃣ Task 삭제
- 삭제 확인 얼럿 필수
- "삭제 후 복구 불가" 경고 표시
- 상위 직급만 삭제 가능

### 7️⃣ 공지 관리 (Notice)
- **등록 권한**: 모든 사용자
- **삭제 권한**: Super Admin만
- 등록 즉시 모든 로그인 사용자의 페이지 상단에 표시
- 배너에서 닫기 가능

### 8️⃣ 관리자 기능 (Super Admin)
#### 팀원 관리
- 팀원 목록 조회 (이름, 이메일, 권한, 상태)
- 권한 변경: Super Admin → Admin → Member
- 상태 변경: 활성/비활성 (로그인 차단, 계정 삭제 아님)
- 팀원 추가

#### 그룹 관리
- 그룹 생성/수정/삭제
- 그룹별 팀원 할당
- 달력 팀뷰 필터에 자동 반영

## 사용자 권한 구조

### 권한 레벨

#### 1. Super Admin (SA)
- ✅ 모든 Task 조회/수정/삭제
- ✅ 팀원 관리 (추가/삭제/권한 변경)
- ✅ 그룹 관리
- ✅ 공지 등록/삭제
- ✅ 관리자 페이지 접근
- 아바타: 보라색 (슈)

#### 2. Admin (A)
- ✅ 본인 Task 조회/수정/삭제
- ✅ 다른 사용자의 Task 수정 가능
- ✅ 팀뷰 달력 접근
- ✅ 그룹 관리
- ✅ 공지 등록 (삭제 불가)
- ❌ 팀원 권한 변경 불가
- 아바타: 주황색 (관)

#### 3. Member (M)
- ✅ 본인 Task만 조회/수정/삭제
- ✅ 개인 달력뷰 접근
- ✅ 공지 등록 가능
- ❌ 다른 사용자 Task 수정 불가
- ❌ 팀뷰 불가
- ❌ 관리자 페이지 불가
- 아바타: 초록색 (M)

### 인증 화면 (3개)
1. **로그인** - 이메일 + 비밀번호
2. **회원가입** - 개인 정보 + 직급 선택
3. **ID/PW 찾기** - 이메일 및 임시 비밀번호 발송

### 메인 화면 (1개)
4. **메인 화면 (개인뷰)** - Daily View with 시간표 + 대기 목록

### 달력 화면 (2개)
5. **개인 달력뷰** - 월간 개인 Task 표시
6. **팀 달력뷰** - 월간 팀 Task + 필터

### 모달 (3개)
7. **Task 등록 모달** - 새 Task 생성
8. **Task 수정 모달** - Admin/SA 전용
9. **Task 상세** - 읽기 전용

### 팝업/얼럿 (3개)
10. **삭제 확인 얼럿** - 복구 불가 경고
11. **지연 팝업** - 사유 입력 + 연장 옵션
12. **공지 등록 모달** - 공지사항 입력

### 관리자 (1개)
13. **Super Admin 페이지** - 팀원 관리 + 그룹 관리

## 데이터 모델

### User (사용자)
```
id: string (UUID)
name: string
email: string (unique)
password: string (hashed)
role: 'SUPER_ADMIN' | 'ADMIN' | 'MEMBER'
status: 'ACTIVE' | 'INACTIVE'
createdAt: Date
updatedAt: Date
```

### Task (업무)
```
id: string (UUID)
title: string
description: string (optional)
assignees: User[] (복수)
startDateTime: DateTime
endDateTime: DateTime
status: 'PENDING' | 'IN_PROGRESS' | 'COMPLETED' | 'DELAYED'
delayReason: string (optional)
delayRecordedAt: DateTime (optional)
createdBy: User
updatedBy: User
createdAt: Date
updatedAt: Date
```

### Notice (공지)
```
id: string (UUID)
title: string
content: string (optional)
createdBy: User
createdAt: Date
```

### Group (그룹)
```
id: string (UUID)
name: string
members: User[]
createdBy: User
createdAt: Date
updatedAt: Date
```

## 시스템 제약

### 기능 제약
1. **기간 Task**: 종료일이 시작일과 다르면 기간 내 매일 달력에 표시
2. **동시 Task**: 같은 시간대 여러 Task는 가로 균등 분할 (최대 5개까지 추천)
3. **지연 처리**: Task 종료 시간 초과 → 지연 상태 자동 변경 + 팝업 표시
4. **권한 검증**: 모든 수정 작업은 권한 확인 후 처리
5. **공지 표시**: 로그인된 모든 사용자에게 상단에 상시 표시

### 성능 제약
1. 달력 월간 표시는 최대 1000개 Task까지 최적화
2. 시간표는 하루 1440분(24시간) 단위로 표시
3. 리스트는 최대 50개 항목 페이지네이션
